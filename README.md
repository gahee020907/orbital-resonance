# ORBITAL RESONANCE (v1.0.4)
## Live Satellite Sonification

> 🌍 **실시간 위성 데이터를 소리로 변환하는 인터랙티브 웹 경험**

## 🔗 바로 체험하기

**👉 [https://gahee020907.github.io/orbital-resonance/](https://gahee020907.github.io/orbital-resonance/)**

접속 후 **"ENTER EXPERIENCE"** 버튼을 클릭하면 바로 시작됩니다.

---

### 🎵 주요 기능

-   **Live Data**: ~2500개 실제 위성을 실시간 추적 (SGP4 + Tone.js)
-   **AI Conductor**: 위성 밀도에 따라 음악적 분위기가 자동 변화
-   **Manual Override**: Scale / Key를 직접 선택하여 하모니 커스터마이징
-   **Sound Explanation**: 각 소리가 왜 발생했는지 실시간 로그로 확인

### 🎹 컨트롤

-   **Presets**: COSMIC / REALISM 모드 전환
-   **Scale / Key**: 음악의 키와 스케일 변경 (예: F# Minor)
-   **Audio Effects**: Volume, Reverb, Delay 조절
-   **Click Satellite**: 위성을 클릭하면 상세 정보 표시

### ⚠️ 오디오 참고사항
-   **"ENTER EXPERIENCE"** 버튼을 클릭해야 오디오가 활성화됩니다 (브라우저 보안 정책)
-   로딩 후 5~10초 대기하면 최적의 오디오 품질을 경험할 수 있습니다
